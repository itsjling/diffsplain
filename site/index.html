      Bring the same file-by-file view to your next PR or local changes. Diffsplain does not change your checkout.

      Run npx diffsplain in a Git checkout to review staged, unstaged, and untracked changes against HEAD. The page updates as files change. Press Ctrl-C to stop.

      Requires Node.js 22.13 or newer and Git. For notes and chat, choose a signed-in Codex, Claude, Copilot, Cursor, or OpenCode CLI. Set a default with diffsplain config agent NAME, pass --agent NAME, or choose from the terminal picker. Cursor Agent needs version 2026.08.11 or newer. PRs also need a signed-in GitHub CLI.

      The page runs locally; agent notes and chat use your provider. Local reviews let the agent inspect your checkout under your user permissions. Use --no-checkout-access to limit agent input to the snapshot, or --no-agent for a plain diff.

      See all command options ↗

      Review a GitHub PR

      npx diffsplain --repo owner/repo --pr 198

      Choose your agent and model

      npx diffsplain --agent claude --model MODEL_NAME

      Compare a remote branch with its default branch

      npx diffsplain --branch feature/my-change
